# Overview

Here are the commands that can be run using panthera.


* cheetah - Run many simulations quickly
* events - Process event streams
* report - Generate a report from a CSV file
* rollup - Rollup simulation data for a cheetah study
* sim - Run the Panthera simulator
* tracing - Tools for tracing workloads with QEMU

## Cheetah sub-commands

* cheetah.xml_report - summarize results from report.xml
* cheetah.errors - generate list of simulation errors

## Tracing/Qemu sub-commands
* tracing.create_image - create a QEMU disk image
* tracing.run - run simple benchmarks
* tracing.trace - run with simple tracer plugin to generate an instruction trace
