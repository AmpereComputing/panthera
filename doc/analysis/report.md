# Reports

The report tool is a tool to generate human readable reports for performance studies.

## Overview

The report tool reads data from a CSV and runs a report script to process the data
and generate 1 or more output files. Most of the reports are designed to read data 
from the CSV file generated by the [rollup](analysis/rollup.md) tool.

## Running the Report Tool

The report tool is a sub-command of the Panthera script. Running with the *--help*
option will describe how to run the tool and list which reports are available. Each
report can be different but they generally generate CSV files that contain
data tables and SVG files for charts of the data.

    install/bin/panthera report --help

You can generate a report that summarizes the key metrics for the study using the
**summary** report.

    install/bin/panthera report study/rollup.by_workload.csv --report summary

This will generate output similar to the following which lists the CSV and SVG

Multiple CSV files can be provided on the command line and the report tool will
process each of them. The report tool generates different output files based 
on the aggregation level of each CSV file, so that by_trace, by_workload and 
by_suite input files will generate separate output report files.

Here is an example command line:

    install/bin/panthera report results/rollup.by_*.csv --report summary

## Writing a Report Script

Report scripts are Python scripts that are read and executed by the report tool. 
Any script in the [reports](../src/ampere/python/panthera/report/reports) directory
can be invoked using the `--report` command line option.

When a report script is executed the `df` variable will be initialized with a
Pandas Dataframe of the data read from the input CSV file. The report can then
manipulate the Dataframe to create the view needed for the report. All of the
functions in the [helpers.py](../src/ampere/python/panthera/report/helpers.py)
can be called directly from the report script. Many reports will call one 
of the `rollup(...)` or `speedup(...)` functions in the `helpers.py` file and then 
generate a CSV file using `create_csv()` and a chart with `create_plot()`.
