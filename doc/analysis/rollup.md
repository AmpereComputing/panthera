# Rolling up simulation data

Panthera has rollup script `install/bin/panthera rollup` to rollup the data from all of the 
simulations. The rollup script aggregates all of the metrics in the
timeseries for each simulation job, and creates a set of CSV files with the aggregate output.
By default the rollup script will generate 3 CSV files.  All 3 files will be in a Tidy Data
format where the columns are the different metrics generated by the simulator.

1. `rollup.by_trace.csv` - each row contains the aggregate metric value for 1 trace
2. `rollup.by_workload.csv` - each row contains the weighted sum of the metric for 1 workload
3. `rollup.by_suite.csv` - each row contains mean of the workload weighted sum for 1 suite 

All of the files that the rollup generates will be created in the study directory.

## Rollup invocation

Options for Rollup can be viewed with `./install/bin/panthera rollup --help`.

The `--formula` parameter specifies a formula file that will be used 
to compute new metrics after the data has been aggregated.

## Formula file

The `rollup_formula` files allow the user to specify
formulas to calculate new metrics from existing columns in the rollup. Each
formula is a Python expression that is evaluated on the rollup data. Metrics can
be specified using the familiar dotted notation. Each term in the expression
must start with *metric*.

For example if the model had data 2 events named _widgets_ and _seconds_, you can compute
a new metric called _wps_ using this formula:

```python
metric.wps = metric.widgets / metric.seconds
```

The [rollup_formula.py](../src/ampere/core/config/rollup/rollup_formula.py) has more examples
of this feature.

It is important to note that the `rollup_formula`, the formulas are applied **after** all
weighting, grouping, and combining is completed. This is by design -- simpoint-based instruction
traces require that all statistics are measured in terms of instructions until after they are
weighted and combined.

### Inclusion of other files

Other formula files can be included within a formula file using:

```python
include(<filename>)
```

Which will evaluate all formulas within that file using the same `metric` as current formula
file. If you want to pass parameters to the file, such as a metric scope, you can do:

```python
include(<filename>, scope=metric.some.unit)
```

Where `scope` within the formula file will refer to `metric.some.unit`.

### Rollup utilities

Common rollup functions are available from `rollup` within the formula file (these map to the
`src/ampere/panthera/rollup/common` modules).

### Timeseries

By default, timeseries are not rolled up, meaning they still have their original
metrics. To apply a formula file to *all* timeseries as well you can run with:

    install/bin/panthera rollup ... --rollup-timeseries

This will also remove factored metrics unless they're specified to keep.
Additionally if you do not want to overwrite the existing files, you can specify
`--timeseries-outdir <dir>` to write the rolled-up files to a different area.

As expected, no aggregation or weighting is applied on timeseries data since the
files are trace-specific.
